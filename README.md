# A potom go na svo

Атмосферное сюжетное 3D-приключение для браузера. Проект рассчитан на мобильные устройства в горизонтальной ориентации и desktop.

## Стек
- React + TypeScript + Vite
- Three.js через React Three Fiber
- Drei для камеры, окружения и контролов
- Zustand для будущего игрового состояния
- Supabase и Colyseus будут подключены отдельными этапами

## Разработка
```bash
npm install
npm run dev
```

## Проверка
```bash
npm run typecheck
npm run build
```

## Статус
Pre-alpha. Сейчас закладываются базовая сцена, визуальная оболочка и архитектура. Сетевые комнаты, сохранения, полноценное управление на сенсорном экране, сюжет и финальные игровые ассеты ещё предстоит реализовать.
